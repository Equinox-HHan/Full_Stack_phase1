# 决策树
## 基本概念
决策树是基于树结构进行判断的，将每个问题的判断分为若干个子判断

决策过程的最终结论对应了判断结果，决策过程中每个判断都是对某项属性的测试

决策树有一个根节点，若干内部节点和若干叶子节点，叶子节点对应于决策结果，其他节点对应了属性测试
```
# Hunt算法体系的基本结构
from collections import Counter
class TreeNode:
    def __init__(self, is_leaf=False, label=None, feature=None):
        self.is_leaf = is_leaf  # 是否为叶节点
        self.label = label  # 如果是叶节点，记录类别
        self.feature = feature  # 如果是非叶节点，记录划分属性
        self.children = {}  # 分支字典：{属性值: 子节点TreeNode}
def majority_class(y):
    """返回标签列表 y 中样本数最多的类别"""
    return Counter(y).most_common(1)[0][0]
def all_same_on_attributes(X, A):
    """判断样本集 X 在属性集 A 上的取值是否全部相同"""
    if not A or len(X) <= 1:
        return True
    first_vals = tuple(X[0][a] for a in A)
    for row in X[1:]:
        if tuple(row[a] for a in A) != first_vals:
            return False
    return True
def choose_best_attribute(D, A):
    """
    占位函数：从 A 中选择最优划分属性 a_*
    实际可使用信息增益 (ID3)、信息增益率 (C4.5) 或基尼指数 (CART) 实现
    """
    # 示例：这里暂且返回 A 中的第一个属性，实际应用需替换为评分函数
    return next(iter(A))
def tree_generate(D, A, feature_values):
    """
    对应伪代码的函数 TreeGenerate(D, A)
    :param D: 训练集，格式为 [(x_dict, y), ...]，其中 x_dict 为 {属性: 值}
    :param A: 当前可用的属性集合 (set)
    :param feature_values: 字典 {属性: 该属性所有可能的取值列表}
    """
    # 1: 生成节点 node
    node = TreeNode()
    X = [x for x, _ in D]
    y = [label for _, label in D]
    # 2-4: if D 中样本全属于同一类别 C then
    if len(set(y)) == 1:
        node.is_leaf = True
        node.label = y[0]
        return node
    # 5-7: if A 为空 OR D 中样本在 A 上取值相同 then
    if len(A) == 0 or all_same_on_attributes(X, A):
        node.is_leaf = True
        node.label = majority_class(y)
        return node
    # 8: 从 A 中选择最优划分属性 a_*
    a_star = choose_best_attribute(D, A)
    node.feature = a_star
    # 9: for a_* 的每一个可能取值 v do
    for v in feature_values[a_star]:
        # 10: 令 D_v 表示 D 中在 a_* 上取值为 v 的样本子集
        D_v = [(x, label) for x, label in D if x[a_star] == v]
        # 11-12: if D_v 为空 then
        if len(D_v) == 0:
            # 将该分支标记为叶节点，类别为 D 中样本最多的类（注意不能直接 return 退出整个循环）
            node.children[v] = TreeNode(is_leaf=True, label=majority_class(y))
        # 13-14: else 递归生成子树
        else:
            node.children[v] = tree_generate(D_v, A - {a_star}, feature_values)
    # 输出：以 node 为根节点的决策树
    return node
```
决策树是递归过程，有三种情况会导致递归返回：
1. 当前节点包含的样本全部为同一类别->直接标记为叶子节点
2. 当前属性集为空或者当前所有样本在当前属性上取值一样（属性相同但标签不同）->将节点标记为叶节点并设为当前样本数最多的类
3. 当前节点的样本集为空->标记为叶节点并将类别设定为父节点样本数最多的类

## 划分选择
决策树最关键的是划分过程：我们希望分支节点包含的样本尽可能属于同一类别（尽可能纯净）
### 信息增益（ID3）
设当前样本集 $D$ 中第 $k$ 类样本所占的比例为 ${P_k}$ 则信息熵：
$$\operatorname{Ent}(D) = -\sum_{k=1}^{|\mathcal{Y}|} p_k \log_2 p_k $$
$\operatorname{Ent}(D)$ 的值越小，则 $D$ 的纯度越高

假定离散属性 $a$ 有 $V$ 个可能的取值 $\{a^1, a^2, \dots, a^V\}$，若使用 $a$ 来对样本集合 $D$ 进行划分，则会产生 $V$ 个分支结点，其中第 $v$ 个分支结点包含了 $D$ 中所有在属性 $a$ 上取值为 $a^v$ 的样本，记为 $D^v$. 

我们可计算出 $D^v$ 的信息熵，再考虑到不同的分支结点所包含的样本数不同，给分支结点赋予权重 $|D^v|/|D|$，即样本数越多的分支结点的影响越大，于是可计算出用属性 $a$ 对样本集合 $D$ 进行划分所获得的“信息增益” (information gain)
$$\operatorname{Gain}(D, a) = \operatorname{Ent}(D) - \sum_{v=1}^{V} \frac{|D^v|}{|D|} \operatorname{Ent}(D^v) . \tag{4.2}$$
一般而言，信息增益越大，则意味着使用属性 $a$ 来进行划分所获得的“纯度提升”越大. 

因此，我们可用信息增益来进行决策树的划分属性选择，即在图 4.2 算法第 8 行选择属性 $a_* = \mathop{\arg\max}\limits_{a \in A} \operatorname{Gain}(D, a)$
### 增益率（C4.5）
实际上，信息增益准则对可取值数目较多的属性有所偏好（同样的样本数属性可取值种类多了每个种类分到的样本自然减少了，自然信息熵就会下降）为减少这种偏好可能带来的不利影响. 我们采用增益率
$$\operatorname{Gain\_ratio}(D, a) = \frac{\operatorname{Gain}(D, a)}{\operatorname{IV}(a)} , \tag{4.3}$$
其中
$$\operatorname{IV}(a) = -\sum_{v=1}^{V} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|} \tag{4.4}$$
称为属性 $a$ 的“固有值”  属性 $a$ 的可能取值数目越多(即 $V$ 越大)，则 $\operatorname{IV}(a)$ 的值通常会越大. 

需要注意的是：增益率通常偏好可取值数目较少的属性

因此`C4.5`算法是先选取信息增益高于平均水平的属性，再从中选择增益率最大的属性
### 基尼指数
CART 决策树使用“基尼指数” (Gini index) 来选择划分属性. 采用与式(4.1) 相同的符号，数据集 $D$ 的纯度可用基尼值来度量:
$$\begin{aligned}\operatorname{Gini}(D) &= \sum_{k=1}^{|\mathcal{Y}|} \sum_{k' \neq k} p_k p_{k'} \\
&= 1 - \sum_{k=1}^{|\mathcal{Y}|} p_k^2 .\end{aligned}$$
$\operatorname{Gini}(D)$ 反映了从数据集 $D$ 中随机抽取两个样本，其类别标记不一致的概率. 因此，$\operatorname{Gini}(D)$ 越小，则数据集 $D$ 的纯度越高.

采用与式(4.2)相同的符号表示，属性 $a$ 的基尼指数定义为
$$\operatorname{Gini\_index}(D, a) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} \operatorname{Gini}(D^v) $$
于是，我们在候选属性集合 $A$ 中，选择那个使得划分后基尼指数最小的属性作为最优划分属性，即 $a_* = \mathop{\arg\min}\limits_{a \in A} \operatorname{Gini\_index}(D, a)$.
## 剪枝优化
决策树不断划分节点会导致某些时候学的太好了，这时候需要通过剪枝防止过拟合
### 1.预剪枝
在决策树不断生成的过程中，对每个节点在划分前进行评估，如果不能带来泛化性能提升则停止划分并标记为叶子节点

些分支的当前划分虽不能提升泛化性能、甚至可能导致泛化性能暂时下降，但在其基础上进行的后续划分却有可能导致性能显著提高

预剪枝基于“贪心”本质禁止这些分支展开，给预剪枝决策树带来了欠拟合的风险.
### 2.后剪枝
后剪枝决策树通常比预剪枝决策树保留了更多的分支.一般情形下后剪枝决策树的欠拟合风险很小，泛化性能往往优于预剪枝决策树.

但后剪枝过程是在生成完全决策树之后进行的，并且要自底向上地对树中的所有非叶结点进行逐一考察，因此其训练时间开销比未剪枝决策树和预剪枝决策树都要大得多
## 处理连续值和缺失值
### 连续值
现实生活中多数属性都是连续值而非离散值

**面对连续值（如身高、温度、密度），决策树不能按每个具体数值分叉，而是通过“切一刀”（二分法），将其转化为“$\le t$”和“$> t$”两个离散分支**

---

#### 一、 为什么要特殊处理连续值？
* 比如“颜色”属性有 `{红, 绿, 蓝}` 3 个值，树就分出 3 个叉

但如果属性是“密度”或“身高”（连续值），样本里的取值可能是 `1.712, 1.725, 1.738...`，几乎**每个样本的数值都不一样**：
1. 可能的取值有无穷多个，没法穷举分叉；
2. 就算强行按现有样本的值分叉，会分出几十上百个分支，每个分支里只有 1 个样本——这棵树就彻底“死记硬背”（过拟合）了，遇到新样本（比如 `1.720`）根本没对应分支可走
因此算法采用**二分法（bi-partition）**：不问“等于多少”，而是问**“是否大于某个阈值 $t$”**

---

#### 二、 怎么找候选切分点？（理解公式 4.7）
假设我们有 4 个样本，按某连续属性（比如“考试分数”）从小到大排序后是：
$$\{60,\ 70,\ 85,\ 95\}$$
我们想找一个阈值 $t$ 把数据切成两半（$D_t^-$ 表示 $\le t$， $D_t^+$ 表示 $> t$）

你可能会想：实数有无穷多个，难道要把 $60.1, 60.2, 60.3\dots$ 全试一遍吗？
**不需要！** 你仔细看就会发现：
* 只要 $t$ 取在 $[60, 70)$ 这个区间里（无论是 $60.1$、$65$ 还是 $69.9$），切出来的两拨人**完全一模一样**——左边都是 `{60}`，右边都是 `{70, 85, 95}`
* 同理，$t$ 取在 $[70, 85)$ 里，左边永远是 `{60, 70}`，右边永远是 `{85, 95}`
所以，对于 $n$ 个不同的数值，中间只有 **$n-1$ 个空隙**会产生不同的划分结果。为了切得最稳妥（离两边样本都最远），书上取每个空隙的**中位点**作为候选切分点（这就是 **公式 4.7**）：
$$T_a = \left\{ \frac{a^i + a^{i+1}}{2} \mid 1 \le i \le n-1 \right\}$$
对于 `{60, 70, 85, 95}` 这 4 个数，我们只需要考察 $4-1 = 3$ 个候选点：$$T_a = \{65,\ 77.5,\ 90\}$$

---

#### 三、 怎么选出“最好的一刀”？（理解公式 4.8）

有了 $n-1$ 个候选切分点后，接下来就跟离散属性一样计算**信息增益（Gain）**来挑最好的：
1. 先假设用 $t=65$ 来切（分成 $\le 65$ 和 $> 65$ 两堆），算一下这样切能带来多少信息增益 $\text{Gain}(D, a, 65)$；
2. 再假设用 $t=77.5$ 来切，算一次 $\text{Gain}(D, a, 77.5)$；
3. 再算 $t=90$ 的 $\text{Gain}(D, a, 90)$
最后，挑出**信息增益最大**的那个切分点作为这个属性的最佳切法，并且把这个最大信息增益当作该属性 $a$ 的最终得分（这就是 **公式 4.8**）：
$$\text{Gain}(D, a) = \max_{t \in T_a} \text{Gain}(D, a, t)$$

这样一来，连续属性就可以拿着这个“最高分”，公平地和其它离散属性（或其它连续属性）一起竞争，看谁来做当前节点的最优划分属性 $a_*$

### 缺失值
在现实数据中，经常会像图中的“西瓜数据集”一样，某些样本的某个特征没记录下来（用 `-` 表示）。如果我们直接把带 `-` 的样本全删掉，会浪费大量宝贵数据

因此，C4.5 等决策树算法提出了一套**“打折算分 + 权重分身”**的策略，专门解决文中开头提出的两个核心问题

---

#### 先提前剧透一个关键概念：样本权重 $w_x$
在根节点（刚开始建树）时，**每个样本的权重默认都是 $w_x = 1$**（代表完整的 1 个样本），此时 $\sum w_x$ 就等于“样本个数”

---

#### 问题 (1)：属性值有缺失，怎么算信息增益来选属性？
**核心思路：只拿“没缺失的样本”算信息增益，然后再按“完整度”打个折**

我们直接拿图里表格的**“色泽”**属性来套用公式 (4.9)~(4.12)：
总共有 17 个瓜（1~8 为“是”，9~17 为“否”），初始权重都是 $1$

1. **找出无缺失子集 $\tilde{D}$**：
   看“色泽”那一列，1 号、5 号、13 号瓜是 `-`（共 3 个缺失），其余 **14 个**瓜都有色泽记录，这就是 $\tilde{D}$

2. **算无缺失比例 $\rho$（公式 4.9）**：
   $$\rho = \frac{\text{无缺失样本权重和}}{\text{总样本权重和}} = \frac{14}{17} \approx 0.824$$

3. **在无缺失的 14 个瓜里算各类别比例 $\tilde{p}_k$ 和各取值比例 $\tilde{r}_v$（公式 4.10、4.11）**：
   * 类别比例（这 14 个瓜里，6 个好瓜，8 个坏瓜）：
     $$\tilde{p}_{\text{是}} = \frac{6}{14}, \quad \tilde{p}_{\text{否}} = \frac{8}{14}$$
   * 属性取值比例（这 14 个瓜里，4 个青绿，6 个乌黑，4 个浅白）：
     $$\tilde{r}_{\text{青绿}} = \frac{4}{14}, \quad \tilde{r}_{\text{乌黑}} = \frac{6}{14}, \quad \tilde{r}_{\text{浅白}} = \frac{4}{14}$$

4. **计算最终信息增益（公式 4.12）**：
   先像平时一样，用上面的 $\tilde{p}_k$ 和 $\tilde{r}_v$ 算出这 14 个无缺失样本的“局部信息增益” $\text{Gain}(\tilde{D}, \text{色泽})$，然后**乘以无缺失比例 $\rho$**：
   $$\text{Gain}(D, \text{色泽}) = \underbrace{\frac{14}{17}}_{\rho\text{（打折系数）}} \times \text{Gain}(\tilde{D}, \text{色泽})$$

---

#### 问题 (2)：如果选定了属性 $a$，缺失值的样本该划进哪个分支？
**核心思路：“分身术”——按其他样本的分布概率，同时划入所有子节点，并拆分权重**

假设经过上面计算，我们最终决定用**“色泽”**来划分当前节点（分出`青绿`、`乌黑`、`浅白`三个子分支）：

* **没缺失的样本（如 2 号瓜，色泽=乌黑）**：
  老老实实只进 `乌黑` 分支，权重保持不变，依然是 $w_2 = 1$
* **有缺失的样本（如 1 号瓜，色泽=`-`）**：
  我们不知道 1 号瓜到底是什么色，既不能直接扔掉，也不能瞎猜一个，于是算法让它**“一分为三”，同时进入三个分支**，并按刚才算出的各颜色占比 $\tilde{r}_v$ 来分配它的新权重（$\tilde{r}_v \cdot w_x$）：
  * 进入 `青绿` 分支：1 号瓜的权重变为 $\tilde{r}_{\text{青绿}} \times 1 = \frac{4}{14} \approx 0.286$
  * 进入 `乌黑` 分支：1 号瓜的权重变为 $\tilde{r}_{\text{乌黑}} \times 1 = \frac{6}{14} \approx 0.429$
  * 进入 `浅白` 分支：1 号瓜的权重变为 $\tilde{r}_{\text{浅白}} \times 1 = \frac{4}{14} \approx 0.286$
你可以发现：$\frac{4}{14} + \frac{6}{14} + \frac{4}{14} = 1$。1 号瓜虽然分身进入了三个子节点，但它的**总权重之和依然守恒等于 1**！

到了下一层子节点继续分裂时（比如在 `青绿` 分支里再按“根蒂”划分），1 号瓜就以 $0.286$ 的权重参与计算（$w_x = 0.286$），这就解释了为什么公式 (4.9)~(4.11) 一开始就要用 $w_x$ 来定义

---

#### 一句话总结
C4.5 处理缺失值非常优雅：
1. **选属性时**：忽略缺失值算增益，再乘以“有值率 $\rho$”作为惩罚；
2. **分样本时**：有值的直接进对应分支，没值的就按已知分布比例 $\tilde{r}_v$，**带着小数权重同时进入所有分支**

## 多变量决策树
在前面几节中，我们学的所有决策树（ID3、C4.5、CART）都有一个共同点：它们都是**单变量决策树（Univariate Decision Tree）**

---

### 一、 单变量决策树的痛点：“画不出斜线”

在单变量决策树中，每个非叶节点只针对**某一个属性**做判断（例如 `密度 <= 0.381` 或 `含糖率 <= 0.126`）

如果我们把样本画在二维平面上（横轴是“密度”，纵轴是“含糖率”）：
* `密度 <= 0.381` 是一条**垂直于横轴的竖线**；
* `含糖率 <= 0.126` 是一条**垂直于纵轴的横线**

也就是说，单变量决策树划出的分类边界，**永远只能平行于坐标轴**。

**这会带来什么问题？**
假设好瓜和坏瓜的真实分界线是一条**斜线**（比如只有当“密度 + 含糖率 > 1”时才是好瓜）：
* 单变量决策树画不出斜线，它只能用无数条横线和竖线拼出一条**“阶梯状”的折线**去逼近这条斜线
* 结果就是：树长得**非常深、非常复杂**，需要切很多刀才能勉强分清，预测效率低，还容易过拟合

```text
单变量决策树（只能画横线竖线）：       多变量决策树（可以直接画斜线）：
  y ^                                  y ^
    |    +  +  |  -                      |    +  +  /  -
    |  +  +    +---                      |  +  +   / -
    |    +  ---|  -                      |    +   /  -
    |  + ---|  -  -                      |  +    / -  -
    +----------------> x                 +----------------> x
     (需要很多段“阶梯”逼近)                 (一刀斜线直接切开！)
```

---

### 二、 多变量决策树的核心思想

为了直接画出“斜线”（高维空间中叫**斜超平面**），多变量决策树把每个非叶节点的判断条件，从“单个属性”升级成了**“多个属性的线性组合”**：
$$\sum_{i=1}^{d} w_i a_i \le t$$
* $a_i$ 是第 $i$ 个属性的值（比如 $a_1$ 是密度，$a_2$ 是含糖率）；
* $w_i$ 是该属性对应的权重；
* $t$ 是阈值；

比如在西瓜问题中，根节点不再问“密度是否小于 0.381”，而是直接问：
> **“$-0.8 \times \text{密度} - 0.044 \times \text{含糖率} \le -0.313$”是否成立？**

**本质变化**：
在单变量决策树里，每个节点只是在做简单的“单属性比大小”；而在多变量决策树里，**每个非叶节点本身就是一个小型的“线性分类器”**（类似感知机或逻辑回归）

这样一来，原本需要七八层“阶梯”才能切开的斜向数据，多变量决策树**往往一两层、一两刀斜切就搞定了**，整棵树会变得极其紧凑和简短

---

### 三、 它是怎么训练的？（权重 $w_i$ 怎么来？）

你可能会好奇：单变量树找切分点只要把现有数值排个序试一遍就行，多变量树里有好几个连续权重 $w_1, w_2, \dots, w_d$ 和阈值 $t$，组合有无穷多种，怎么找最优解呢？

核心思路是：**不再逐个属性算信息增益，而是在每个节点上直接训练一个线性分类器。** 常见方法有：
1. **OC1 算法（Oblique Classifier 1，最具代表性）**：
   先随便初始化一条斜线（一组权重），然后采用**贪心爬山法**：固定其他权重，只微调某一个属性的权重 $w_i$，看能不能让信息增益（或不纯度下降）变大；
   
   为了防止卡在局部最优解，还会加入**随机扰动**，试着把斜线往其他方向抖一抖，挑出表现最好的那条斜线
2. **直接借用线性模型**：
   在当前节点的样本上，直接跑一次感知机（Perceptron）、逻辑回归（Logistic Regression）或支持向量机（Linear SVM），直接把求出来的分类超平面拿来做当前节点的切分面，然后再对左右两边的子集递归下去

### 四、 优缺点与现实应用
既然斜决策树这么强、树又浅，为什么我们在 `scikit-learn` 或日常竞赛（Kaggle）里很少直接用它？

**优点：**
* 对具有线性相关性、斜向分布的数据，模型极度精简，树深度浅，泛化能力往往比深层的单变量树更好

**缺点（也是现实中用得少的原因）：**
1. **可解释性大幅下降**：
   单变量树的规则人类一眼就能看懂（“如果密度 $>0.38$ 且纹理清晰，就是好瓜”）；但多变量树的规则是“如果 $0.72 \times \text{密度} - 1.35 \times \text{含糖率} + 0.18 \times \text{敲声} \le 0.4$”，业务人员很难直观理解这个公式代表什么物理意义
2. **训练代价高**：
   单变量树找最优切分点非常快；而多变量树在**每一个节点**都要做一次高维权重优化（甚至多次随机扰动），计算复杂度暴增
3. **离散属性不友好**：
   线性组合天生要求属性是连续数值，如果遇到“色泽={青绿, 乌黑, 浅白}”这种离散类别，还得先做独热编码（One-Hot）转换成数值才能相乘
   
**现代机器学习的替代方案：**

在今天的工程实践中，人们通常不去费劲训练一棵复杂的多变量决策树，而是反过来——**用大量简单的单变量决策树组成集成模型（如随机森林、XGBoost、LightGBM）**。通过把几百棵不同切法的“阶梯树”投票或累加起来，同样能平滑地拟合出任意斜线甚至曲线边界，而且训练速度极快、稳健性极高
